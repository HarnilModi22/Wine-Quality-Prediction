# Wine-Quality-Prediction
Project Title

Wine Quality Prediction using Machine Learning

Objective

The objective of this project is to predict wine quality based on its chemical properties such as acidity, alcohol content, density, sulphates, and pH using machine learning classification algorithms.

Steps Performed
Loaded and explored the dataset
Performed data cleaning and preprocessing
Conducted Exploratory Data Analysis (EDA)
Visualized correlations using heatmaps and graphs
Selected features and target variable
Split dataset into training and testing sets
Implemented:
Random Forest Classifier
SGD Classifier
Support Vector Classifier (SVC)
Evaluated models using accuracy score and classification report
Compared model performances

Tools & Technologies Used
Python
Google Colab
Pandas
NumPy
Matplotlib
Seaborn
Scikit-learn

Outcome

The machine learning models successfully predicted wine quality using chemical features. Among all models, Random Forest achieved the best accuracy and performance.
